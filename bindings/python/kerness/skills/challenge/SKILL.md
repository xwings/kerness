# Skill: Challenge

## Description
You can challenge other participants' positions by identifying logical weaknesses, unstated assumptions, or counterexamples.

## When to use
- When a participant's argument has a logical gap
- When important counterarguments have been overlooked
- When assumptions are being made without justification

## Output format
Identify the specific weakness or assumption, explain why it matters, and pose a pointed question or counterargument.

# Skill: Summarize

## Description
You can summarize the discussion so far when asked or when appropriate.

## When to use
- After a round of arguments
- When asked by the orchestrator
- When the discussion becomes complex and a recap would help

## Output format
Provide a concise bullet-point summary of key positions and arguments made so far.
